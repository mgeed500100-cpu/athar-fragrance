# Original Athar artwork

Generated for this project with OpenAI ImageGen, September 2026. No external brand photography or UI source code was copied. These images depict unbranded fictional products, not catalog photography or customer submissions.

- hero.webp: three unbranded fluted glass perfume bottles with black caps on limestone, ivory sunlight and burgundy fabric; right side clear for live Arabic typography.
- bottles.webp: transparent 3:1 atlas, five equally spaced bottles in clear, rose, amber, burgundy and black. CSS selects one fifth without five separate downloads.
- gift.webp: open burgundy presentation box, two unbranded bottles and ivory silk ribbon with warm cinematic lighting.

Sources: src/assets/images/athar; webpack copies to public/images/athar. The optimization utility takes three original PNG paths and exports resized WebP via sharp. No image API or credentials are needed at storefront runtime.
